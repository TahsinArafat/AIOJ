# IDE Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a standalone IDE page at `/ide` with Monaco editor, custom stdin runner, and low-priority judge submission capability.

**Architecture:** Single new page component (`IDE.tsx`) with a horizontal split layout — left: Monaco code editor with language selector, right: custom input textarea + output panel. Both "Run" and "Submit" buttons use the existing `POST /api/submissions/run` endpoint (synchronous, no queue priority). The API layer is extended with a new `ideRun` method that passes priority metadata.

**Tech Stack:** React 19, TypeScript, Tailwind CSS, Monaco Editor (`@monaco-editor/react`), lucide-react icons

## Task 2: Create IDE Page

**Files:**

- [ ] **Step 1: Create the IDE page component**

Write the complete `IDE.tsx` file. This is a single file with everything inlined.

```tsx
import { useState } from 'react'
import { Play, Send, Terminal, Loader2 } from 'lucide-react'
import CodeEditor from '../components/CodeEditor'
import { api } from '../lib/api'

const LANGS = [
    { value: 'cpp-gpp-64', label: 'GNU G++17 7.3.0 (64 bit)' },
    { value: 'cpp-gpp-32', label: 'GNU G++14 6.4.0 (32 bit)' },
    { value: 'c-gcc-64', label: 'GNU GCC C11 9.2.0 (64 bit)' },
    { value: 'c-gcc-32', label: 'GNU GCC C11 9.2.0 (32 bit)' },
    { value: 'cpp-clang', label: 'Clang++17' },
    { value: 'python', label: 'Python 3.8.10' },
    { value: 'java', label: 'Java 11.0.6' },
    { value: 'rust', label: 'Rust 1.75.0' },
    { value: 'nodejs', label: 'Node.js 18.16.1' },
    { value: 'csharp', label: 'Mono C# 6.12.0' },
]

const TEMPLATE_CODE: Record<string, string> = {
    'cpp-gpp-64': `#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}`,
    'cpp-gpp-32': `#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}`,
    'cpp-clang': `#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}`,
    'c-gcc-64': `#include <stdio.h>

int main() {
    printf("Hello, World!\\n");
    return 0;
}`,
    'c-gcc-32': `#include <stdio.h>

int main() {
    printf("Hello, World!\\n");
    return 0;
}`,
    'python': `print("Hello, World!")`,
    'java': `import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}`,
    'rust': `fn main() {
    println!("Hello, World!");
}`,
    'nodejs': `console.log("Hello, World!");`,
    'csharp': `using System;

class Program {
    static void Main() {
        Console.WriteLine("Hello, World!");
    }
}`,
}

interface RunOutput {
    stdout: string
    stderr: string
    compile_output: string
    time_used: number
    memory_used: number
    status: string
}

export default function IDE() {
    const [language, setLanguage] = useState('cpp-gpp-64')
    const [code, setCode] = useState(TEMPLATE_CODE['cpp-gpp-64'])
    const [customInput, setCustomInput] = useState('')
    const [output, setOutput] = useState<RunOutput | null>(null)
    const [running, setRunning] = useState(false)
    const [submitting, setSubmitting] = useState(false)

    const handleLanguageChange = (newLang: string) => {
        setLanguage(newLang)
        setCode(TEMPLATE_CODE[newLang] || '')
    }

    const handleRun = async () => {
        if (!code.trim()) return
        setRunning(true)
        setOutput(null)
        try {
            const res = await api.submissions.run({
                source_code: code,
                language,
                input: customInput,
            })
            setOutput(res)
        } catch (err: any) {
            setOutput({
                stdout: '',
                stderr: err?.message || 'Failed to run code',
                compile_output: '',
                time_used: 0,
                memory_used: 0,
                status: 'error',
            })
        } finally {
            setRunning(false)
        }
    }

    const handleSubmit = async () => {
        if (!code.trim()) return
        setSubmitting(true)
        setOutput(null)
        try {
            const res = await api.ideRun({
                source_code: code,
                language,
                input: customInput,
                priority: 2,
            })
            setOutput(res)
        } catch (err: any) {
            setOutput({
                stdout: '',
                stderr: err?.message || 'Failed to submit code',
                compile_output: '',
                time_used: 0,
                memory_used: 0,
                status: 'error',
            })
        } finally {
            setSubmitting(false)
        }
    }

    return (
        <div className="max-w-[1400px] mx-auto px-6 py-6">
            {/* Header */}
            <div className="flex items-center justify-between mb-4">
                <h1 className="text-2xl font-bold text-gray-900 dark:text-white">IDE</h1>
                <div className="flex items-center gap-3">
                    {/* Language Selector */}
                    <select
                        value={language}
                        onChange={(e) => handleLanguageChange(e.target.value)}
                        className="border border-gray-300 dark:border-gray-600 rounded px-3 py-1.5 text-sm focus:outline-none focus:ring-2 focus:ring-blue-500 bg-white dark:bg-gray-800 text-gray-900 dark:text-gray-100"
                    >
                        {LANGS.map((l) => (
                            <option key={l.value} value={l.value}>
                                {l.label}
                            </option>
                        ))}
                    </select>

                    {/* Run Button */}
                    <button
                        onClick={handleRun}
                        disabled={running || submitting || !code.trim()}
                        className="flex items-center gap-1.5 bg-green-600 hover:bg-green-700 text-white px-3 py-1.5 rounded text-sm font-medium disabled:opacity-50 transition-colors cursor-pointer"
                    >
                        {running ? (
                            <Loader2 className="w-4 h-4 animate-spin" />
                        ) : (
                            <Play className="w-4 h-4" />
                        )}
                        Run
                    </button>

                    {/* Submit Button */}
                    <button
                        onClick={handleSubmit}
                        disabled={running || submitting || !code.trim()}
                        className="flex items-center gap-1.5 bg-blue-600 hover:bg-blue-700 text-white px-3 py-1.5 rounded text-sm font-medium disabled:opacity-50 transition-colors cursor-pointer"
                    >
                        {submitting ? (
                            <Loader2 className="w-4 h-4 animate-spin" />
                        ) : (
                            <Send className="w-4 h-4" />
                        )}
                        Submit (Low Priority)
                    </button>
                </div>
            </div>

            {/* Split Layout */}
            <div className="flex gap-4" style={{ height: 'calc(100vh - 160px)' }}>
                {/* Left: Code Editor */}
                <div className="flex-1 border border-gray-200 dark:border-gray-700 rounded-lg overflow-hidden bg-white dark:bg-gray-800">
                    <CodeEditor
                        language={language}
                        value={code}
                        onChange={setCode}
                        height="100%"
                    />
                </div>

                {/* Right: Output Panel */}
                <div className="w-[400px] flex flex-col gap-4">
                    {/* Custom Input */}
                    <div className="border border-gray-200 dark:border-gray-700 rounded-lg bg-white dark:bg-gray-800 flex-1 flex flex-col">
                        <div className="px-3 py-2 border-b border-gray-200 dark:border-gray-700 flex items-center gap-2">
                            <Terminal className="w-4 h-4 text-gray-500 dark:text-gray-400" />
                            <span className="text-sm font-medium text-gray-700 dark:text-gray-300">Custom Input</span>
                        </div>
                        <textarea
                            value={customInput}
                            onChange={(e) => setCustomInput(e.target.value)}
                            placeholder="Enter stdin here..."
                            className="flex-1 w-full font-mono text-xs border-0 p-2.5 bg-transparent text-gray-900 dark:text-gray-100 placeholder-gray-400 dark:placeholder-gray-500 resize-none focus:outline-none"
                        />
                    </div>

                    {/* Output */}
                    <div className="border border-gray-200 dark:border-gray-700 rounded-lg bg-white dark:bg-gray-800 flex-[2] flex flex-col">
                        <div className="px-3 py-2 border-b border-gray-200 dark:border-gray-700 flex items-center justify-between">
                            <span className="text-sm font-medium text-gray-700 dark:text-gray-300">Output</span>
                            {output && (
                                <div className="flex items-center gap-3 text-xs text-gray-500 dark:text-gray-400">
                                    <span>Time: {output.time_used}ms</span>
                                    <span>Memory: {(output.memory_used / 1024 / 1024).toFixed(1)}MB</span>
                                </div>
                            )}
                        </div>
                        <div className="flex-1 overflow-auto p-2.5">
                            {!output && !running && !submitting && (
                                <p className="text-gray-400 dark:text-gray-500 text-sm text-center py-8">
                                    Click "Run" or "Submit" to see output
                                </p>
                            )}
                            {running && (
                                <p className="text-gray-400 dark:text-gray-500 text-sm text-center py-8">
                                    Running...
                                </p>
                            )}
                            {submitting && (
                                <p className="text-gray-400 dark:text-gray-500 text-sm text-center py-8">
                                    Submitting...
                                </p>
                            )}
                            {output && (
                                <div className="space-y-3">
                                    {/* Status Badge */}
                                    <div className="flex items-center gap-2">
                                        <span className={`text-xs font-medium px-2 py-0.5 rounded ${
                                            output.status === 'Accepted' || output.status === 'accepted'
                                                ? 'bg-green-100 text-green-800 dark:bg-green-900/30 dark:text-green-400'
                                                : 'bg-red-100 text-red-800 dark:bg-red-900/30 dark:text-red-400'
                                        }`}>
                                            {output.status}
                                        </span>
                                    </div>

                                    {/* Compile Output */}
                                    {output.compile_output && (
                                        <div>
                                            <h4 className="text-xs font-medium text-gray-500 dark:text-gray-400 mb-1">Compile Output</h4>
                                            <pre className="text-xs font-mono text-gray-900 dark:text-gray-100 bg-gray-50 dark:bg-gray-900 rounded p-2 overflow-auto max-h-32 whitespace-pre-wrap">
                                                {output.compile_output}
                                            </pre>
                                        </div>
                                    )}

                                    {/* Stdout */}
                                    <div>
                                        <h4 className="text-xs font-medium text-gray-500 dark:text-gray-400 mb-1">Stdout</h4>
                                        <pre className="text-xs font-mono text-gray-900 dark:text-gray-100 bg-gray-50 dark:bg-gray-900 rounded p-2 overflow-auto max-h-48 whitespace-pre-wrap">
                                            {output.stdout || '(empty)'}
                                        </pre>
                                    </div>

                                    {/* Stderr */}
                                    {output.stderr && (
                                        <div>
                                            <h4 className="text-xs font-medium text-gray-500 dark:text-gray-400 mb-1">Stderr</h4>
                                            <pre className="text-xs font-mono text-red-600 dark:text-red-400 bg-gray-50 dark:bg-gray-900 rounded p-2 overflow-auto max-h-48 whitespace-pre-wrap">
                                                {output.stderr}
                                            </pre>
                                        </div>
                                    )}
                                </div>
                            )}
                        </div>
                    </div>
                </div>
            </div>
        </div>
    )
}
```

## Notes

### Priority Handling

The `POST /api/submissions/run` endpoint is **synchronous** — it compiles and executes code immediately via the go-judge sandbox and returns results. It does **not** use the submission queue, so the `priority` field in the request body is currently ignored by the backend's `CustomRun` handler.

The `ideRun` method in `api.ts` sends `priority: 2` in the request body. This is forward-compatible: when the backend is updated to respect priority on the run endpoint (or when a queue-based IDE submission is added), the frontend is already sending the correct value.

For true low-priority queuing, the backend would need to either:
1. Support a queue-based run endpoint (async with priority), or
2. Accept `problem_id: null` on the `Create` endpoint for IDE submissions

Both are backend-only changes; no frontend changes needed.

### Design Decisions

1. **Split layout**: Left (flex-1) = editor, Right (400px fixed) = input + output. This avoids resizable panes complexity while providing adequate space.

2. **No draft persistence**: Unlike ProblemDetail which saves code per-problem, the IDE uses a simple default template. Users can persist via their own workflow.

3. **Shared LANGS/TEMPLATE_CODE**: Copied from ProblemDetail.tsx rather than extracting to a shared module. This follows YAGNI — if these need to be shared later, extraction is straightforward.

4. **Output panel**: Shows compile_output, stdout, stderr, time, and memory. Status badge uses green/red coloring based on whether the status indicates success.
