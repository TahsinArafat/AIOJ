- **Rust similarity engine (`2fd903a`)** — the only CPU-bound job in the product moved to Rust. `rust/plagiarism/` = `aioj-plagiarism`, a short-lived subprocess: one JSON request on stdin, NDJSON on stdout (one `{"pair":…}` per flag, then one `{"summary":…}`). **No cgo** (backend stays `CGO_ENABLED=0`), **no resident service** (no new port/auth surface). `internal/plagiarism/service.go` batches the whole report to it and writes the pairs.
  - Measured, 44,850 pairs (300 subs/problem), ~900-token sources: original `CompareCodes` loop ~96 s → `NativeEngine` 17.0 s → Rust 0.68 s. On **short** sources (~90 tokens) the engines tie (12.6 vs 13.4 ms) — the process boundary costs as much as the scan, so Rust only pays off when LCS work is real. ~7,700× of the win is algorithmic (tokenize once, intersection prefilter, no per-pair matrix); Rust adds the last 25× (bit-parallel LCS + rayon).
  - **Both engines must stay exact.** `Engine` contract in `similarity.go`; `NativeEngine` (Go) is the fallback *and* the differential reference. Prefilter is only legal because `LCS ≤ multiset intersection` (sound, can only over-estimate). `engine_parity_test.go` asserts pair sets + similarity values + pair count vs `CompareCodes` at 10 thresholds; `TestRustTokenizerMatchesGo` diffs tokenizers case-by-case. The Rust tokenizer **deliberately reproduces Go regex quirks** (`//` stripped inside string literals → `"http://x"` loses its tail; unterminated `/*` kept; `v1.5` → `v1.` + `NUM`) — "fixing" them moves every score.
  - `PLAGIARISM_ENGINE` = `auto` (default; Rust if found, else Go, logged) | `native` | `rust` (fails startup rather than downgrading). `PLAGIARISM_RUST_BIN` search order: env → `./bin` → `<module>/bin` → `rust/plagiarism/target/{release,debug}` → `PATH`. Image sets `PLAGIARISM_RUST_BIN=/app/bin/aioj-plagiarism`.
  - **Gotchas**: no `serde` derive — **proc-macros cannot build for `*-musl`**, so the crate uses `serde_json::Value` + hand-shaped JSON (`serde_json::to_string` for escaping). Static link via `RUSTFLAGS=-C target-feature=+crt-static` (MSRV 1.80, from rayon). The Docker stage builds a stub `main.rs` first for layer caching, so it **must** `touch src/*.rs` before the real build — Docker normalizes mtimes and cargo otherwise skips the rebuild and ships `fn main(){}` (which exits 0 silently; this actually happened). The stage asserts `--version` and a real scan afterwards.
  - Commands: `make rust-build` | `rust-test` | `rust-lint` | `rust-fmt` | `test-parity`. Without `rust-build` everything is green: Rust tests skip, Go engine used. Docs `rust/plagiarism/README.md` + an `AI_CONTEXT.md` section.
